# Audio assets

Drop royalty-free audio files in this folder. The app auto-discovers
them via `/audio/manifest.json` (generated by the audio-manifest Vite
plugin in dev; written into the prod bundle at build time).

## Supported formats

- `.mp3`, `.wav`, `.m4a`, `.mp4`, `.ogg`, `.aac`, `.flac`, `.webm`

Drop in whichever your browser can play. HTML5 `<audio>` handles all
of these on modern browsers; safest pick is mp3 if you want
universal support.

## Playlist groups

Files are grouped by filename prefix:

| Prefix | Group | When it plays |
|---|---|---|
| `lobby-*` or `lobby.*` | Lobby | MainMenu + the online-mode lobby screens |
| (anything else)        | Gameplay | During an active match |

Within each group, the player **shuffles** and auto-advances when a
track ends. If a group is empty, the player falls back to the other
group so there's always music (assuming you've added at least one
file).

## Examples

```
public/audio/
├── lobby-coqui-chill.mp3       ← plays on the main menu
├── lobby-bomba.wav             ← plays on the main menu
├── reggaeton-summer.mp3        ← plays during a match
├── perreo-1.m4a                ← plays during a match
└── salsa-bomba.ogg             ← plays during a match
```

## Controls

Top-right speaker icon in the app:
- Master volume slider (0–100%)
- Mute toggle
- Music on/off (independent of SFX)
- SFX on/off (synth click / swoosh / fanfare; works without any
  files dropped in here)
